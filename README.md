Over het project

Voor dit project hebben we een squad page gemaakt voor onze klas. Op de website kunnen bezoekers de verschillende studenten bekijken en meer informatie over hen vinden.

We hebben geprobeerd om de website niet alleen overzichtelijk te maken, maar ook een eigen uitstraling te geven. De desktopversie is geïnspireerd op mappen op een computer en de mobiele versie heeft meer de uitstraling van een iPhone homescreen.

De website is gemaakt met HTML, CSS en JavaScript. De informatie van de studenten wordt vanuit een JSON-bestand ingeladen.

⸻
 Opvallende features

1.  Mac-folder design

Op desktop hebben we gekozen voor een ontwerp dat lijkt op mappen op een Mac. Met de pijltjes kan je door verschillende studenten navigeren.

2.  iPhone homescreen op mobiel

Op mobiel verandert het ontwerp naar een homescreen-achtige interface. De studenten worden als apps weergegeven en je kunt tussen verschillende pagina’s swipen.

3.  Studenten vanuit JSON

De studenten worden niet allemaal handmatig in de HTML gezet. De namen, foto’s en links staan in een JSON-bestand. JavaScript haalt deze informatie op en gebruikt het om de studenten op de website te tonen.
